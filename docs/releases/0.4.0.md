# Whale Tide 0.4.0

Conversation readability, simplified.

- **Removed the per-message halo.** The `.dshwt-prose::before` panels from
  0.3.0 read as white cards over the solid ASCII whales, and adjacent messages
  merged into one big white board. They are gone; there is no text-shadow
  either.
- **Deeper ebb instead**: `conversationOpacity` defaults to 0.10 (was 0.16),
  so the ocean itself recedes and the prose stays clean. The setting remains
  adjustable.
- **Kept** the 14 surface tokens (bg layers, bubble, sidebar, labels, borders)
  and the 0.74/0.78 frosted composer with 3px blur, opaque popovers and
  0.5px borders at DPR>=2.
- **Migration**: a stored `conversationOpacity` equal to the old 0.16 default
  is migrated to 0.10 once; custom values are preserved.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.4.0/dsh-whale-tide-0.4.0.tgz
```
