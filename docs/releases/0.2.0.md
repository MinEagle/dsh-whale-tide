# Whale Tide 0.2.0

Full control set, and real dark mode.

- **24 settings**, grouped as Tide and display / Whales / Ocean and fish /
  Composer glass. They mirror dsh-ascii-whales 0.1.5: whale count, species
  (humpback / orca), size, body swing, turn agility, tail frequency, speed,
  accent colour, colourful shimmer, eye background, wake, cell size, grid
  opacity, fish count, character style (ASCII / Hanzi), frosted composer,
  glass blur and glass opacity, plus this plugin's tide controls.
- **Live vs rebuild**: count / species / size / fish count / cell size rebuild
  the engine; every other control applies without interrupting the swim.
- **Dark mode fixed**: the scheme is read from `data-ds-theme-source`,
  `body[data-ds-dark-theme]`, `color-scheme` and the theme service instead of
  the (plugin-owned) body background. Backdrop, sidebar glass, text halo,
  composer glass and the canvas palette all switch together, and a separate
  `data-dsh-whale-tide-ui` attribute keeps host chrome readable when
  "follow light / dark" is off.
- **Hero text halo**: both themes keep the empty-session copy readable where a
  whale passes underneath.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.2.0/dsh-whale-tide-0.2.0.tgz
```
