# Whale Tide 0.9.2

Cell-size control.

- **Cell size** setting (`cellSize`, 6–12 px, default 9 px); `8 px` matches
  dsh-ascii-whales' 8×12 cells, `9 px` is the default performance compromise.
- The dsh-quiet template now uses the configured cell width instead of
  `W/124`, so fish and whale blocks can be made finer without changing the
  engine.
- Existing 0.9.1 features remain: five-species fish, spatial hash, fish/whale
  colors, glint, sidebar fish.

Note: smaller cells increase the cell count (9 px ≈ 10k cells vs 5.8k at the
old 12 px), so 8 px is noticeably heavier than 9 px; use 10–11 px if CPU rises.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.9.2/dsh-whale-tide-0.9.2.tgz
```
