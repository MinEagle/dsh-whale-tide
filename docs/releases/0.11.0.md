# Whale Tide 0.11.0

Scenes: ocean, snow, birds.

- **Scene selector** in Settings (`scene`: ocean / snow / birds); mutually
  exclusive with the existing ocean.
- **Snow**: seeded flakes with depth, sway and wrap-around; density 0.2–2.
- **Birds**: small V-formations with flapping wing glyphs, flying across the
  viewport; density 0.2–2.
- Both reuse the existing 30fps / DPR 1.5 glyph renderer, an offscreen static
  background, and the same accent colour; no extra engine or canvas.
- Added scene screenshots and settings docs.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.11.0/dsh-whale-tide-0.11.0.tgz
```
