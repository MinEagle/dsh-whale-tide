# Whale Tide 0.1.0

First public release.

- A code-drawn humpback whale and fish schools behind DeepSeek Harness.
- Zero runtime image assets: glyphs, cells, wake and dot grid are rendered on a
  canvas.
- High tide in an empty conversation; ebbs to 16% opacity and 30% of the fish
  while a conversation is active.
- Frosted composer only at high tide; conversation text gets a soft halo.
- Eight settings, saved under `dsh-whale-tide:v1`, with restore defaults.
- Respects `prefers-reduced-motion` and pauses while the page is hidden.
- Removes the layer, canvas, styles and body attributes on unload.
- No build step; compatible with DSH `>=0.2.0-rc.2 <0.3.0-0`.
