# Whale Tide 0.10.0

Visual polish and a single accent colour.

- **One accent colour** (`accentColor`, default `#a9bde8`) replaces the separate
  fish and whale colours; the whale body blocks use a darker shade of the same
  hue so the silhouette still reads solid.
- **Five species now look different**: sardine `·`, anchovy `=`, silverside
  `.`, mackerel `~`, goby `*`, drawn at three relative sizes with a gentle
  vertical bob, so schools no longer read as a single uniform dot field.
- **Stronger whale silhouette**: body blocks slightly darker, ridge and eye
  cells keep their highlight.
- Settings count 14 → 13 (two colour rows merged into one).
- Screenshots regenerated for light/dark hero, conversation and settings.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.10.0/dsh-whale-tide-0.10.0.tgz
```
