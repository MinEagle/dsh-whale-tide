# Whale Tide 0.5.0

Performance release.

- **Adaptive quality**: hero renders at DPR 1.5 / 30fps; an active conversation
  renders at DPR 1.0 / 18fps with 3 edge samples instead of 5 and a whale mask
  refreshed every other frame.
- **Blur pause**: `window.blur` stops the rAF loop entirely; `focus` resumes.
  Page-hidden and reduced-motion pauses are unchanged.
- **Desynchronized canvas** context for lower compositor overhead.
- Measured on the same large conversation (8s): TaskDuration 22% -> 17%,
  ScriptDuration 16% -> 9%; active canvas pixels 4.7M -> 1.17M (-75%) and
  rendered frames 60 -> 18 (-70%). Host baseline with the plugin disabled is
  about 10% TaskDuration / 35-40% renderer CPU, so the plugin is not the sole
  source of high renderer percentages.
- No visual change in the empty state; conversation whales remain visible at
  the 0.20 ebb.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.5.0/dsh-whale-tide-0.5.0.tgz
```
