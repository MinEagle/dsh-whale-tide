# Whale Tide 0.1.1

Fix release: use the real dsh-ascii-whales swimming implementation.

- **Swimming**: replaced the simplified bottom-strip patrol with the actual
  `World` / `OceanEngine` / `AsciiRenderer` from
  [dsh-ascii-whales](https://github.com/Chael-Chael/dsh-ascii-whales) 0.1.5
  (MIT, itself adapted from ascii-sharks). Three humpback whales now roam the
  whole viewport with the upstream boids, spines, wake and pointer reactions.
- **Conversation window**: kept dsh-quiet's full-window treatment — the fixed
  backdrop, the transparent conversation surface, the 16% ebb and the
  inherited text halo.
- **Settings**: the same eight settings; density and conversationDensity now
  drive `renderer.fishRatio` without restarting the world; speed/colour/theme
  update live through `setAppearance`.
- **Assets**: all README screenshots/GIF regenerated with the upstream engine.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.1.1/dsh-whale-tide-0.1.1.tgz
```
