# Whale Tide 0.2.1

Small fix on top of 0.2.0.

- **Hanzi mode now switches the font**: choosing "Hanzi" for the character style
  re-reads the canvas font stack, so glyphs render with a serif CJK face and
  the grid becomes square, instead of staying monospace.
- Documentation: recorded the reduced-motion and hanzi verification results.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.2.1/dsh-whale-tide-0.2.1.tgz
```
