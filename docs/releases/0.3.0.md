# Whale Tide 0.3.0

Conversation readability, following dsh-quiet's three-layer approach.

- **Surface tokens**: 14 host tokens now switch to light frosted values —
  `bg-base` transparent, `bg-layer-1` 0.84/0.88, sidebar 0.55/0.60, bubble
  0.92/0.90, labels and borders included. Menus stay opaque. All overrides are
  registered through `theme.overrideTokens` and removed on unload.
- **Prose halo**: every assistant message wrapper is tagged `.dshwt-prose` by
  structure (no hashed class names) and gets a local ::before halo panel with
  2px blur, replacing the old full-container 26px text-shadow.
- **Composer**: the frosted composer now stays on in conversation at
  0.74/0.78 with 3px blur; `[data-trigger-menu]` stays opaque; borders are
  0.5px at DPR>=2.
- Verified in the live desktop app in both light and dark, and cleanup leaves
  no tokens, classes, styles or body attributes behind.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.3.0/dsh-whale-tide-0.3.0.tgz
```
