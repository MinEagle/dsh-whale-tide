# Whale Tide 0.4.1

Visibility fix for the no-halo conversation mode.

- 0.4.0 lowered `conversationOpacity` to 0.10. At 10% a blue whale body over
  white is ~#eef0ff, which is almost invisible on real displays. The default
  is now **0.20**, still with no halo or text-shadow.
- One-time migration via a schema marker: stored values equal to the old
  defaults (0.16 or 0.10) move to 0.20; values changed later by the user are
  preserved.
- `npm test` covers the migration; the live desktop app was re-checked in light
  and dark.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.4.1/dsh-whale-tide-0.4.1.tgz
```
