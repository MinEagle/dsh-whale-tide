# Whale Tide 0.9.0

Fish polish on the dsh-quiet template.

- **Five-species dsh-ascii-whales fish** carried into dsh-quiet: depth, glint,
  schooling, predator evasion and eat/respawn.
- **Spatial hash** for fish neighbours (Int32Array buckets, 3×3 cells) so the
  fish count can scale to 200 without quadratic work.
- **Fish colour** (`#a9bde8` default), **fish glint** 0–2 and exact
  **fish count** 20–200 settings.
- **Sidebar fish**: 0–12 fish stay inside the sidebar during a conversation,
  so it no longer goes blank for long stretches; the resident whale logic is
  untouched.
- Keeps dsh-quiet's 30 fps / DPR 1.5 glyph-atlas render path.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.9.0/dsh-whale-tide-0.9.0.tgz
```
