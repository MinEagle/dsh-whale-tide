# Whale Tide 0.6.0

Conversation interface, now modelled on dsh-quiet.

- **D — canvas follows the chat area**: the backdrop is placed from the window
  top-left to the chat area's right edge; the sidebar has its own
  `.dshwt-sidebar-glass` blur surface.
- **E — creatures leave, one stays**: on entering a conversation, the other
  whales head for the nearest edge at 4x speed and fish scatter; one resident
  whale is scaled to the sidebar and stays behind its frosted glass. Returning
  to an empty session re-seeds the world and fades everything back in.
- **C — local prose halo**: assistant message wrappers get `.dshwt-prose` and a
  soft `::before` (white 0.55 / dark 0.60, 12px shadow, 1px blur), not the
  heavy 0.3.0 cards because the water is calm now.
- Keeps the 0.5.0 performance work: adaptive DPR/fps, low-detail conversation
  rendering, blur pause.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.6.0/dsh-whale-tide-0.6.0.tgz
```
