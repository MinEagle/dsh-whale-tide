# Whale Tide 0.9.1

Whale colour and finer species rendering.

- **Whale colour** setting (`whaleColor`, default `#c3c8d2`) via a separate
  coloured glyph atlas, so whales keep their `drawImage` performance instead of
  per-glyph `fillText`.
- **Fish species glyphs**: sardine `-`, anchovy `=`, silverside `.`, mackerel
  `~`, goby `*`; depth and glint still drive alpha.
- **Spatial hash** retained for fish neighbours; `fishCount` 20–200.
- **Sidebar fish** setting 0–12, default 6, so the sidebar stays alive during a
  conversation.
- 13 settings in total; `npm test` 12/12.

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.9.1/dsh-whale-tide-0.9.1.tgz
```
