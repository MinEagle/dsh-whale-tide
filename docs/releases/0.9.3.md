# Whale Tide 0.9.3

Fixes the blank-looking hero and stale-slot error.

- **Hero is populated immediately**: `enterFromEdges()` no longer runs on the
  first mount, so the pod and fish start on screen instead of crawling in for
  ~30s (which looked like "nothing is happening").
- **Duplicate chat slot**: `conversation.chat.node` is registered once per
  apply and guarded with try/catch, so a stale module instance can no longer
  throw `slot already declared` and break the takeover.
- Default cell size stays 9px; the setting applies live (verified 6↔12px).

Install:

```bash
dsh plugin --profile <profile> add \
  https://github.com/MinEagle/dsh-whale-tide/releases/download/v0.9.3/dsh-whale-tide-0.9.3.tgz
```
